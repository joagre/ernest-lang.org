Ernest

Ernest is a small functional language for concurrent programs, on the Erlang runtime. It has two concepts: functions, with Hindley-Milner types, and processes with typed mailboxes, the only way to affect the world.

  • The repository, where the language is built.
  • The report, which defines the language, its library and its toolchain.
  • The releases, each with its notes.

Served by ernest-httpd, a server written in Ernest.
